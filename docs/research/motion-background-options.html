Motion and background options

Every demo runs in the real dossier palette (tokens copied from global.css). Toggle the theme and the motion switch to judge both palettes and the reduced state. Status: proposal, nothing here is on the site yet. The note with findings and the recommendation: motion-background-options.md.

01 - Motion options

Seven candidates, each built on the page's existing language: dither, stepped time, one lamp. All are CSS-first; only the count-up needs a few lines of JS.

M1 - Dither rule march

The section dither rule crawls sideways in 2px steps, like a screentone breathing. Static rule above, marching rule below. cost: css only

The current view() reveal glides. A stepped reveal reads as print: the row lands in six jumps. Same timing, different taste. cost: one line per rule

M4 - Dust motes in the lamp light

The lofi loopable element: a few 2px motes drifting inside the lit area. CSS only here; the site can run the dormant PixelField dust canvas instead. cost: css / 4 kB canvas

M5 - Sakura petals (taste call)

The same drift with 4px pixel petals in the accent. Reads clearly Japanese, and clearly riskier: show it to a hiring reviewer first. cost: css only

M6 - Seigaiha wave band

The traditional wave pattern rebuilt in CSS as 2px pixel stairs (radii step 12px), sitting still above the footer, or marching in slow steps. See also B2. cost: css only

02 - Background options

Four ways to carry "lofi Japanese manga + 2D pixel" on the surface without breaking the dossier rules (one signature object, no second colour, accent reserved for values).

B1a - Screentone wash, uniform

A 1px dot screen at 6px pitch, 9 percent ink. Reads as paper for a printed comic. Keep it under ten percent where text lives. cost: css only

Every surface gains the dot screen of a printed manga page.

Body text sits above the screen, still at full contrast.

B1b - Screentone ramp, corner

Two dot grids, a coarse one fading from the corner and a fine one under it: the manga shading gradient. Decorative layer only, never under text. cost: css only

decorative - no text inside

B2 - Seigaiha band

The wave pattern as a quiet band above the footer. Pixel stairs, border ink, 50 percent. The page gets a horizon without a second object. cost: css only

B3 - Dusk window (plate stars)

The plate becomes the room's window at dusk: pixel stars and a crescent in the dark palette, the lamp glow at the corner. Static; no twinkle. cost: css only, dark palette

portrait

B5 - Manga panel frame

The plate reads as one manga panel: ink corner blocks, or a cut corner. One style only, keep the caption. cost: css only
